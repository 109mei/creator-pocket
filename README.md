# creator pocket

小さくつくって、ゆっくり育つ。縦画面向けの、のんびりしたクリエイター生活ゲームです。

## 遊び方

1. 今日のヒントに合わせてアイデアを選ぶ
2. ショート／ひとこと、仕上げの方法を選ぶ
3. 架空の作品を投稿し、届いた理由を読む
4. ゲーム内コインでカメラ・ライト・編集デスクを育てる
5. 元気が少ない日は休む。7日で一週間をふり返る

ゲームの時間は操作したときだけ進みます。課金、連続ログイン報酬、実際のSNSへの自動投稿はありません。投稿・反応・フォロワー・コインはすべて架空です。

## 動画ラウンジ

YouTube / Xの公式埋め込みで、実際の動画・公開投稿を見られます。初期キューにはNASAとX Publishで確認した公開例を入れています。YouTube Shorts、通常動画、youtu.be、X/Twitterの投稿URLも追加できます。NASA・JAXA・ESA・NASA JPLの公開フィードから最新30本を自動追加します。手動URLは別に30件まで保存し、重複はまとめます。YouTubeの個人向けおすすめ取得ではなく、選定した4チャンネルの有限キューです。通常動画やライブ配信の予告も含まれ、Shorts専用ではありません。

- 外部プレーヤーは明示的な読み込み操作後に接続
- YouTubeはプライバシー強化埋め込み、Xは独立したsandbox iframeを使用
- 外部サービスにはIPアドレス・ブラウザー情報などが送信される場合があります
- 視聴・いいね・共有はゲームの報酬と連動しません
- 非公開・削除・年齢/地域制限・埋め込み不可・接続制限により再生できない場合は、元のサービスへのリンクを利用できます
- YouTubeやXが提供・後援するゲームではありません

### 無料の自動更新

公開AtomフィードをGitHub Actionsで約6時間ごとに確認し、静的な動画一覧を再公開します。APIキー・有料API・新しいアカウントは不要です。ページを開くと、その時点の一覧を読み込みます。動画の再生は引き続き明示的な外部コンテンツ許可が必要です。

通信障害時は直近の正常なデータを残し、更新日時と状態を表示します。GitHubの定期実行には遅延があり、リポジトリーの活動が60日ない場合などは停止することがあります。リアルタイム・無期限の保証ではありません。自動追加をキューから外すと、このブラウザーでは再追加しません（除外IDは直近100件）。

実装・出典・無料枠と運用上の注意は [YOUTUBE_UPDATES.md](./YOUTUBE_UPDATES.md) を参照してください。

### 縦画面モード

「縦画面いっぱいで見る」から、ブラウザーの表示領域いっぱいに動画を表示できます。プレーヤーの上下にある専用帯を上にスワイプすると次、下にスワイプすると前へ切り替わります。公式プレーヤー内のタッチ操作は各サービスに属するため、そこを覆って操作を横取りしません。前後ボタンとキーボードの上下キーも使えます。

外部動画の有効化はこのモードを閉じるまでの一時的な許可です。次の項目へ切り替えたときも公式プレーヤーを読み込みますが、自動再生しません。実際の再生は公式プレーヤーのボタンから行います。退出・ダイアログ表示でプレーヤーを破棄し、外部接続の許可を解除します。端末のネイティブFullscreen APIではなく、画面高に合わせた表示なのでブラウザーの操作バーが残る場合があります。

## 開発

Node.js 22以上。実行時依存パッケージはありません。jsdomはコントローラーのテストにのみ使用します。

```
npm ci --ignore-scripts
npm test
npm run check
npm run update:videos
npm run build
npm run dev
```

開発サーバーは http://localhost:4177 。配信ファイルはdist/。GitHub Pagesのサブディレクトリーにも対応する相対パスを使用しています。

## 保存

進行と動画URLキューはブラウザーのlocalStorageにのみ保存します。ゲーム用アカウント・実行時バックエンド・独自アクセス解析はありません。公開動画メタデータだけをGitHub Actionsで定期取得します。保存を利用できない場合も、画面を閉じるまで遊べます。設定からゲーム進行を初期化できます。

## 検証範囲

ルール、URL検証、保存復元、キーボードのフォーカス遷移、7日間ループ、外部コンテンツの明示的読み込み、動画と報酬の分離を自動テストします。jsdomのテストは実ブラウザーの見た目・タッチ操作・動画再生を保証しません。外部動画の可用性は各サービスの設定と接続環境に依存します。
