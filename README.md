# creator pocket

小さくつくって、ゆっくり育つ。縦画面向けの、のんびりしたクリエイター生活ゲームです。

## 遊び方

1. 最近の声と常連の好みを見て、企画を選ぶ
2. 形式 → 入口 → 中身 → 仕上げを、一つずつ決める
3. 費用と懸念を確認してゲーム内に投稿する
4. 次の日へ進み、再生・登録者の増減・反応から次の工夫を考える
5. 休息と無料制作を使いながら、収益化・架空の案件・銀の記念盾を目指す

投稿しただけでは登録者やコインは増えません。需要や伝え方が合わなければ停滞し、強い期待とのずれは登録解除にもつながります。日数に上限はなく、7日ごとの強制終了はありません。下部の三つの画面は「見る / 作る / マイチャンネル」です。

ゲームの時間は操作したときだけ進みます。課金、連続ログイン報酬、実際のSNSへの自動投稿はありません。投稿・反応・フォロワー・コインはすべて架空です。

## 動画ラウンジ

YouTubeの動画は「YouTubeで再生」から外部の公式ページで開きます。このゲーム内ではYouTubeの動画・画像・プレーヤーを読み込みません。APIキーやData API、IFrame Player APIは使用しません。Xの公開投稿のみ、許可後に独立したsandbox iframeで読み込めます。

YouTube Shorts、通常動画、youtu.be、X/Twitterの投稿URLを追加できます。選定した8チャンネルの公開Atomフィードから最大30件のメタデータを自動追加します。手動URLは別に30件まで保存し、重複をまとめます。個人向けYouTubeおすすめの取得ではなく、有限のキューです。通常動画やライブ予告も含みます。

- カードを先に表示し、好み・URL追加・一覧・更新情報は補助パネルにまとめています
- YouTubeは公式リンクのみ。Xは明示的な読み込み操作後に接続
- Xの読み込み時にはIPアドレス・ブラウザー情報などが送られる場合があります
- 視聴・♡はゲームの報酬と連動しません
- 非公開・削除・年齢や地域制限のコンテンツは、外部ページでも再生できない場合があります
- YouTubeやXが提供・後援するゲームではありません

### 無料の自動更新

公開AtomフィードをGitHub Actionsで約6時間ごとに確認し、静的な動画一覧を再公開します。APIキー・有料API・新しいアカウントは不要です。ページを開くと、その時点の一覧を読み込みます。YouTubeの再生は外部の公式ページで行います。RSSメタデータに視聴者の情報や動画ファイルは含めません。

通信障害時は直近の正常なデータを残し、更新日時と状態を表示します。GitHubの定期実行には遅延があり、リポジトリーの活動が60日ない場合などは停止することがあります。リアルタイム・無期限の保証ではありません。自動追加をキューから外すと、このブラウザーでは再追加しません（除外IDは直近100件）。

実装・出典・無料枠と運用上の注意は [YOUTUBE_UPDATES.md](./YOUTUBE_UPDATES.md) を参照してください。

### 縦画面モード

「1枚ずつ見る」から、画面いっぱいのカード表示に切り替わります。右側の専用帯を上下にスワイプすると前後に移動します。前後ボタンとキーボードの上下キーも使えます。YouTubeは常に公式ページへのリンクです。

Xの有効化はこのモードを閉じるまでの一時的な許可で、次のX投稿に切り替えた場合も適用されます。YouTubeのカードには適用しません。Xプレーヤー内の操作は横取りせず、退出・ダイアログ表示でプレーヤーを破棄して許可を解除します。端末のネイティブFullscreen APIではなく、画面高に合わせた表示です。

### この端末の好み

「好み・ジャンル」を開くと、好きなジャンルを複数選べます。選ばずに進むことも、あとで変更することもできます。♡ボタンでこの端末に好みを保存し、右の専用帯を2回タップしても「好き」にできます。2回タップは解除せず、解除には♡ボタンを使います。公式プレーヤー内のタップ操作は横取りしません。

好みは現在の有限キューの並び順に反映し、異なるジャンルも少し混ぜます。YouTubeやXへいいねを送ったり、個人向けのおすすめを取得したりする機能ではありません。分類がわからない手動URLにジャンルを決めつけません。選んだジャンルが一覧にない場合は、そのことを表示します。ジャンルと直近100件の好みはこの端末のlocalStorageにのみ保存し、ゲームの数字とは連動しません。再生中の動画やすでに進んだキューの並びは、♡操作で飛ばさないように保ちます。

## 開発

Node.js 22以上。実行時依存パッケージはありません。jsdomはコントローラーのテストにのみ使用します。

```
npm ci --ignore-scripts
npm test
npm run check
npm run update:videos
npm run build
npm run dev
```

開発サーバーは http://localhost:4177 。配信ファイルはdist/。GitHub Pagesのサブディレクトリーにも対応する相対パスを使用しています。

## 保存

進行と動画URLキューはブラウザーのlocalStorageにのみ保存します。ゲーム用アカウント・実行時バックエンド・独自アクセス解析はありません。公開動画メタデータだけをGitHub Actionsで定期取得します。保存を利用できない場合も、画面を閉じるまで遊べます。設定からゲーム進行を初期化できます。

## 検証範囲

ルール、URL検証、保存復元、キーボードのフォーカス遷移、継続キャンペーン、外部コンテンツの明示的読み込み、動画と報酬の分離を自動テストします。jsdomのテストは実ブラウザーの見た目・タッチ操作・動画再生を保証しません。外部動画の可用性は各サービスの設定と接続環境に依存します。


## 戦略シミュレーション v2

- キャンペーンと投稿IDで固定した乱数を使用。リロードで結果を引き直せません
- 公開時は制作費のみを消費し、次のゲーム内日に登録・解除・収益を一度だけ精算
- 同じジャンルではなく、同じ企画と切り口の反復で新規への広がりを減らします
- 投稿の反応と、外部動画の好み・♡・視聴履歴は別のデータです
- 収益化は登録者100、直近7投稿1,500再生、直近5投稿で高満足3本、信頼60がゲーム内条件。申請後の翌ゲーム日に承認
- 承認後に公開した投稿のみ収益対象。広告収益の小数相当は繰り越し。制作費・機材費・収入を分けて記録
- 架空のリクエスト・補足対応・案件は一度に一件。反復クリックによる報酬はありません
- 登録者1,000人で「CreatorPocket 銀の記念盾」。実際のYouTube表彰ではなく、獲得後の登録解除でも残ります
- 旧v1の登録者・コイン・機材・投稿は引き継ぎます。旧投稿は新しい収益の対象になりません
- 下書きは同じゲーム内日の間、閉じても再読み込みしても選択を保持します

これらの数値はすべてゲーム用の調整値であり、実在SNSのアルゴリズム・収益・審査条件を再現しません。[モデルと検証の詳細](CREATOR_SIMULATION.md)。
